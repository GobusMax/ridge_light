# osmand-aidl

Verbatim copy of OsmAnd's AIDL API module (`OsmAnd-api/src` in
https://github.com/osmandapp/OsmAnd, commit `bd35a0ed2a974849ddafe0fc24f7072976e50783`), rearranged into the
standard `src/main/aidl` / `src/main/java` layout. Do not edit: transaction codes follow the
method order in `IOsmAndAidlInterface.aidl`, so it must match what OsmAnd ships.

OsmAnd states the AIDL API has "no license issues - available for all possible purposes"
(https://www.osmand.net/docs/technical/osmand-api-sdk/).
